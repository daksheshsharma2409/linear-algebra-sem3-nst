Now name the algorithm: Gaussian elimination
We have already discovered the ingredients. Now we package them into an algorithm.
Gaussian elimination
Gaussian elimination uses elementary row operations to transform a system into row echelon
form, where the equations become progressively simpler from top to bottom.
8.1
Pivot and row echelon form
A pivot position is the position of the ﬁrst nonzero entry in a nonzero row after the matrix has been
organised in echelon form.
A matrix is in row echelon form when:
1. all zero rows, if any, are at the bottom;

Why the staircase matters
Moving downward, each equation depends on fewer unknowns. The ﬁnal nonzero row is the easiest
equation. Then we work upward by back substitution.
Recipe for a Perfect Matrix - (using Gaussian Elimination)
1. Find the ﬁrst non-zero entry in the leftmost column. This is your
pivot.
2. If needed, swap rows to bring the pivot into position.
3. Use the pivot row to create zeros below the pivot.
4. Move to the next column and repeat the process.
5. Continue until all pivots form a staircase pattern.
Remember: Use only the three valid row operations and never change
the solution of the system!
